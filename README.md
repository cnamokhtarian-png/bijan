# بیژن — گربه‌ای در خیابان

یک بازی آرکید مرورگری: گربه‌ای نارنجی با شال قرمز در خیابان‌های نئونی شب. بپر، سُر بخور، ماهی
جمع کن و نُه جانت را بسنج.

- **فنی:** React 19 + TypeScript + Vite + Tailwind v4، گرافیک با Canvas 2D (بدون تصویر/صدا asset)
- **خروجی:** یک فایل HTML تنها (`vite-plugin-singlefile`) — همه‌ی JS، CSS و فونت داخل همان فایل inline است
- **رکوردها:** در `localStorage` مرورگر بازیکن (بدون بک‌اند، بدون حساب کاربری)

## اجرا

```bash
npm install
npm run dev      # localhost:5173
npm run build    # خروجی: dist/index.html (یک فایل)
```

## اتصال به دانش‌بوک

این بازی در صفحه‌ی `/bijan` سایت [دانش‌بوک] داخل `iframe` اجرا می‌شود و یک بنر نازک تبلیغاتی
بالای بنر اصلی صفحه‌ی خانه دارد.

```bash
npm run build
cp dist/index.html ../danesh_book3096-final/public/games/bijan/index.html
```

اگر بازی مستقل دیپلوی شود، در دانش‌بوک فقط متغیر `BIJAN_GAME_URL` روی آدرس آن تنظیم می‌شود.

## نکته‌ی فونت

فونت وزیرمتن خودمیزبان است (`src/assets/fonts`)، عمداً بدون Google Fonts: در ایران گوگل‌فونت
کند یا مسدود است و رندر متن کل بازی را بلاک می‌کرد. همین دو فایل هم داخل خروجی تک‌فایلی
inline می‌شوند تا بازی بدون هیچ درخواست شبکه‌ای بیرونی اجرا شود.
