# بازی «بیژن» در دانش‌بوک

بازی آرکید **بیژن؛ گربه‌ای در خیابان** (Endless runner مرورگری) با یک بنر نازک روی صفحه‌ی خانه
به دانش‌بوک اضافه شده است.

## چه چیزی اضافه شده؟

| مسیر | توضیح |
|---|---|
| `src/components/GameBanner.tsx` | بنر نازک تبلیغاتی، بالای بنر اصلی صفحه‌ی خانه. تصویر + متن + دکمه‌ی «بازی کن»؛ کل نوار لینک است |
| `src/app/bijan/page.tsx` | صفحه‌ی میزبان بازی: هدر تصویری، قاب بازی، راهنمای کنترل‌ها، متادیتای سئو و داده ساختاریافته `VideoGame` |
| `src/components/GameFrame.tsx` | قاب `iframe` بازی + نوار ابزار (شروع دوباره، تمام‌صفحه، باز کردن در تب جدید) و حالت بارگذاری |
| `src/lib/game.ts` | پیکربندی مسیرها، تصاویر و آدرس بازی |
| `public/games/bijan/index.html` | خود بازی — خروجی تک‌فایلی Vite (همه JS/CSS/فونت inline) |
| `public/images/bijan/*` | تصویر بنر (مربع ۲۴۰px)، هدر (۱۴۴۰px) و کارت Open Graph (۱۲۰۰×۶۳۰) |

همچنین: لینک «بازی بیژن» در منوی کنار، آدرس `/bijan` در `sitemap.xml`، و
`frame-src` در CSP برای نمایش قاب بازی.

## چرا iframe؟

بازی یک اپ مستقل است. اجرای آن داخل `iframe` سه مزیت دارد:

1. استایل و فونت‌های بازی (تم تیره/نئونی) با تم روشن دانش‌بوک تداخل نمی‌کند.
2. `overflow: hidden` و مدیریت کلیدهای بازی فقط داخل قاب اثر دارد و صفحه‌ی سایت را قفل نمی‌کند.
3. رکوردهای بازی در `localStorage` همان مبدأ می‌مانند و با آپدیت سایت پاک نمی‌شوند.

## به‌روزرسانی بازی

```bash
# در ریپوی بازی (bijan)
npm install
npm run build

# فایل نهایی را جایگزین نسخه‌ی داخل دانش‌بوک کنید
cp dist/index.html ../danesh_book3096-final/public/games/bijan/index.html
```

خروجی Vite به لطف `vite-plugin-singlefile` یک فایل تنهاست (~۴۶۰KB، همه‌ی دارایی‌ها inline)،
پس نیازی به کپی پوشه‌ی `assets` نیست.

## میزبانی روی دامنه‌ی جدا (اختیاری)

اگر خواستید بازی مستقل دیپلوی شود (مثلاً همان ریپوی `bijan` روی Vercel):

```env
BIJAN_GAME_URL=https://<game-deployment>.vercel.app
```

- `src/lib/game.ts` همین آدرس را داخل `iframe` می‌گذارد.
- `next.config.ts` مبدأ همان آدرس را خودکار به `frame-src` اضافه می‌کند؛ در غیر این صورت مرورگر
  قاب را با خطای CSP بلاک می‌کند.
- دکمه‌ی «باز کردن در تب جدید» همیشه به همین آدرس می‌رود.

بدون این متغیر، بازی از همان فایل داخلی `public/games/bijan/index.html` سرو می‌شود و هیچ
تنظیمی لازم نیست.

## نکته‌های فنی

- فونت بازی (وزیرمتن) قبلاً از `fonts.googleapis.com` لود می‌شد؛ حالا خودمیزبان است و داخل
  همان تک‌فایل inline می‌شود. دلیل: در ایران گوگل‌فونت کند/مسدود است و رندر متن بازی را بلاک می‌کرد.
- روی iOS، `requestFullscreen` برای `div` پشتیبانی نمی‌شود؛ در این حالت دکمه‌ی تمام‌صفحه
  به‌جای خطا بازی را در تب جدید باز می‌کند.
- برای بازی با کیبورد، کاربر باید اول یک‌بار داخل قاب کلیک کند (فوکوس iframe)؛ این محدودیت
  مرورگر است، نه باگ.
- فایل بازی با هدر `X-Frame-Options: SAMEORIGIN` و `frame-ancestors 'self'` سرو می‌شود؛
  فقط داخل خود دانش‌بوک قابل نمایش است.
